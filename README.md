## Getting Started

### Online

Visit the webapp at: https://scouthaus.lovable.app/

### Locally

Prerequisite <br />
[![Bun](https://skills.syvixor.com/api/icons?i=bun)][bun]
[![Git](https://skills.syvixor.com/api/icons?i=git)][git]

[bun]: https://bun.sh/
[git]: https://git-scm.com

1. Clone this repository using [Git][git]
	```sh
	git clone https://github.com/pongy-debug/scouthaus.git
	cd scouthaus
	```
2. Install dependencies using [Bun][bun]
	```sh
	bun i
	```
3. Start the development server
	```sh
	bun dev
	```
4. Visit http://localhost:8080 (`Local` port displayed in your terminal)
